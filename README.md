# Baby Santilú — landing page demo

Landing page responsive para **Baby Santilú**, una tienda chilena de juguetes y accesorios orientados a la estimulación temprana.

## Ver localmente

No requiere instalación ni compilación. Abre `index.html` o sirve la carpeta con cualquier servidor estático.

## Publicación

El proyecto está preparado para GitHub Pages mediante el flujo incluido en `.github/workflows/pages.yml`. En GitHub, selecciona **Settings → Pages → Source: GitHub Actions**.

## Contenido editable

- `index.html`: textos, secciones y enlaces.
- `styles.css`: identidad visual y adaptación móvil.
- `script.js`: selector por etapa, navegación y microinteracciones.
- `assets/`: capturas proporcionadas por la marca.

> La orientación de compra descrita en la demo no sustituye una evaluación médica individual.
